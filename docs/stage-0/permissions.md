# Subuser permission keys

Observed constants in Panel `app/Models/Permission.php`. Keep exact strings; unknown keys block import review and never grant access. Owner, administrator and application credentials have separate policies; Wings-only permissions must not be assignable to subusers. Test every key with a grant, no grant and wrong-server subject, including JWT revocation. Application and node rights are separate from these keys.
